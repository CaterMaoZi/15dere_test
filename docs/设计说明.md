# 设计说明（15 维综合体系）

> 本文档说明「十五维恋爱属性测试」的维度体系、题库结构与评分规则，内容与 `js/` 代码一致。
> 本测试是网络娱乐与自我探索工具，**不是经心理测量学验证的量表，不能用于临床诊断或预测恋爱成功率。**

## 一、从两层到扁平：15 维综合体系

早期版本采用「5 基础类型 + 20 隐藏属性」两层体系。重构后合并为**扁平的 15 个维度**（去重并删除 6 个高重叠维）：

**15 维**（`js/core/keys.js` 的 `DIM_KEYS`）：
天然、轻浮、电波、地雷、重力、浮力、三无、傲娇、暴娇、病娇、反差、清醒、傲慢、残念、郁娇。

**合并逻辑**：原 5 类型 + 20 属性，其中 4 个名称（天然/轻浮/电波/重力）两层重名，去重得 21 项；
再删除 6 个可被其他维涵盖的高重叠维——深海(≈三无+慢热)、粘人/依赖(≈地雷黏着/重力投入)、
月光(≈电波浪漫面)、控制(≈重力/地雷占有面)、傲沉(≈傲娇+傲慢)——正好剩 15 维，彼此区分度更高。

每题选项直接给 15 维中若干维记分，不再有「类型 vs 属性」的层级之分。

## 二、维度含义的来源核实

维度源自**日系 ACGN moe 角色属性 + J-fashion 亚文化**，经公开资料（维基词条等）核实含义后设计：

- **傲娇(tsundere)**：tsun-tsun(冷淡) + dere-dere(害羞亲昵)，"外硬内软"。
- **病娇(yandere)**：yanderu(病态) + dere，由爱生占有、怕失去，向外发作（监控、独占、归咎他人）。
- **三无(kuudere)**：外表冷静、几乎无表情、情绪克制。
- **电波(denpa，"电磁波")**：像在接收别人收不到的信号，活在自己的频率里、精神共鸣独特。
- **地雷(jirai-kei，"地雷类型")**：**核心是情绪不稳定、起伏剧烈、随时毫无预警引爆**——源自"地雷女"
  （外表甜美无害、内里有破坏性，像定时炸弹，踩中触发点就炸）。"怕被抛弃"仅是引爆诱因之一，
  本质是**不可预测的情绪波动性**。与暴娇(一贯稳定地外放强硬)、病娇(对特定对象的执念占有)区分。
- 其余为同谱系派生属性（天然/轻浮/重力/浮力/反差/清醒/傲慢/残念/郁娇）。

此外，还通过小红书实地查阅高赞笔记校正了每一维在中文语境里的"极端面"（详见 `docs/参考文献.md` 第七节）。

### 核心区分框架：怕失去 × 向内/向外

最容易混淆的 5 个"深情焦虑"维，用「怕失去时，情绪向内承受还是向外发作」这条轴清晰分开
（源自小红书实证，原话："病娇把你锁进地下室；地雷半夜打五十个电话；重力只是静静说句承诺让你逃不开引力"；
"病娇对外、郁娇对内"）：

| 维度 | 方向 | 极端表现 |
|---|---|---|
| 病娇 bingjiao | 向外·占有 | 监控、独占、归咎他人（"都是别人勾引你"） |
| 地雷 dilei | 向外·情绪失控 | 突然爆雷、夺命连环 call、质问"还爱不爱我" |
| 暴娇 baojiao | 向外·炸毛 | 一点就炸、炸完又心软服软 |
| 重力 zhongli | 向内·沉重承受 | 自我牺牲、用承诺和愧疚感维系、精神内耗 |
| 郁娇 yujiao | 向内·自责 | 都是我的错、过度讨好、卑微到尘埃 |

题库用 Q508/Q509/Q708 等题直接测这条轴；评分自测对"向内≠向外"有专门断言。

详见 `docs/参考文献.md`。

## 三、题库结构（约 90 题，10 模块）

见 `js/data/questions.js`。模块主题：真实自我 / 主动行动 / 情感表达 / **安全感与情绪波动(地雷核心)** /
嫉妒占有边界 / **冲突爆发修复** / 付出承诺 / 新鲜自由 / 隐藏需求反差 / 理想关系。

**题型**：frequency 行为频率 / scenario 情境 / action 主动行为 / counterfactual 反事实对照 /
self 自我认知 / actual 实际行为 / likert 倾向自评（给一句情境陈述，选"这是我／有时是我／中立／有时不是我／不是我"五级，赞同度越高给该维 +2/+1/0/−1/−2）。

**选项标注**：`scores` 直接是 `{维度key: 分值}`（可正可负 → 反向计分）；`skip:true` 为「不适用/未发生」不计分。
对照题附 `consistencyGroup / compareRole(self|actual) / compareDim / contrastSelf / contrastActual`。

**覆盖**：15 维每维 ≥9 道题触及（实测最低 9），满足「不单凭一题判定」。

## 四、评分规则（`js/core/scoring.js`）

1. **累加**：遍历已答题，选中选项的 `scores` ×权重 累加到各维；同时累加每题各维理论最高/最低分。
2. **归一化**：`(实得−最低)/(最高−最低)×100`，得 0–100。这是本测试内部相对倾向，非真实概率。
3. **降序排行** `dimRank`：15 维按分从高到低——对应结果页的雷达图与排行条。
4. **占比** `proportions`：各维分占总分比例（备用）。
5. **突出维** `topDims`：排行取前 3–5，过滤「关联已答题 < 3」的低证据维；不足 3 则补足并标低证据。
6. **反差**：同维度配对 self/actual 题，归一差 ≥ 20 生成一条。
7. **漏答/不适用**：整题或该选项不计分，不计入理论最高/最低，避免放大。
8. **低确定性**：已答 < 60% 时提示。

阈值见 `SCORING_CONFIG`（TOP_MIN_EVIDENCE=3、TOP_N=5、TOP_MIN=3、CONTRAST_GAP=20、LOW_CONF_RATIO=0.6）。

## 五、结果页板块（`js/core/render.js`）

主维卡 → **15 维雷达图(内联 SVG)** → **15 维降序排行条** → 突出维详解 → 隐藏需求 →
恋爱反差(证据足才显示) → 冲突模式 → 容易被吸引 → 维度匹配(趣味参考) → 成长建议 →
完整属性图鉴(`codex.html`) → 分享卡(Canvas 导出 PNG，含迷你雷达)。全部由实际答题动态生成。

## 六、避免偏差

- 选项代表不同应对**策略**而非对错，避免「成熟理性」选项恒高分（社会赞许偏差）。
- 每个人格的介绍（含「极端的一面」字段）深入刻画其原型谱系，但**不再逐条附带医学/免责声明**；
  关于"网络娱乐、非诊断、极端面与现实胁迫/伤害行为是两回事、占有不等于爱"的统一声明**集中放在首页**一处。
- 不以性别、性取向或文化差异作为固定行为模式。
